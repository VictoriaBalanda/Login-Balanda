# Login - Instituto Superior Santa María

## Descripción

Este proyecto es una página de login realizada con HTML, CSS y JavaScript. Permite ingresar con diferentes usuarios y redirige a una página según los datos ingresados. Si los datos son incorrectos, muestra un mensaje de error. También tiene un tercer usuario de invitado.

## Usuarios de prueba

El usuario admin tiene la contraseña admin y accede a la página de preceptor.

El usuario user tiene la contraseña user y accede a la página de estudiante.

El usuario invitado tiene la contraseña 1234 y accede a la página de invitado.
